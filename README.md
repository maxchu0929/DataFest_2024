# DataFest 2024 with CourseKata
### DataFest 2024 was an event held at UCLA in which teams were given several large data sets of student interactions on the CourseKata website, an educational learning platform, and given a tight 48-hour period to freely analyze and derive actionable insights from the data.
### This project was done in a team of five: Maxwell Chu, Evan Garcia, Hannah Le, Evan Dixon, and Julian Sandjaja.
- Preprocessed and merged data sets of student website interaction totaling 300,000+ rows and 50+ columns and conducted EDA with visualizations.
- Verified pain points where student performance significantly declined using t-tests, and determined most significant predictors of these trends.
- Created and delivered a Tableau dashboard to CourseKata representatives; presented actionable insights and solutions to improve user experience.
- Befriended four student teammates, divided work by assessing strengths of each person, and coordinated independent findings into a focused goal.

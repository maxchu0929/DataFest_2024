# DataFest 2024 with CourseKata
### DataFest 2024 was an annual event held at UCLA in which teams were given several large data sets of student interactions on the CourseKata website, an educational learning platform.
### This project was done in a team of five: Maxwell Chu, Evan Garcia, Hannah Le, Evan Dixon, and Julian Sandjaja
- Cleaned and preprocessed several data sets totaling over 300,000 rows and combined them to conduct EDA with visualizations.
- Verified pain points where student performance significantly declined using t-tests, and determined most significant predictors of these trends.
- Created and delivered a Tableau dashboard to CourseKata representatives; suggested practical solutions to improve user experience and learning.
- Befriended four student teammates, divided work by assessing strengths of each person, and coordinated independent findings into a focused goal.
